第 1 步

欢迎使用

Northmu Docs 是一个面向个人使用的文档与笔记管理系统，基于 ThinkPHP 8 与 MySQL 5.7 构建。

文档编辑
富文本与 Markdown 双模式，支持版本历史与草稿。
可见性控制
公开、加密、私有三种级别，分类自动继承。
附件与备份
附件库统一管理，支持数据库与附件打包备份。
可选 Redis 缓存
启用后站点数据与文档内容将缓存加速。
安装前请准备好 MySQL 数据库账号（或允许程序自动创建数据库），并确认 Web 运行目录指向 public。
预计 1-2 分钟完成

第 3 步

数据库配置

必填
不存在时程序会尝试自动创建；仅允许字母、数字、下划线
请确保数据库用户拥有建表权限；若数据库不存在，程序会尝试自动创建。
第 4 步

Redis 缓存

可跳过
不启用时站点直接读取数据库，可随时在后台「缓存管理」中开启。启用后站点设置、分类树与文档内容会写入 Redis 加速访问。
仅影响本站缓存键，清空缓存不会误删其他应用数据。
第 5 步

必填

安装完成后请妥善保管管理员密码，并保持登录验证码开启。
