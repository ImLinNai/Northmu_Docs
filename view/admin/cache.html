说明

  • Redis 不可用时前台自动回退数据库查询，不会影响访问。
  • 缓存键固定命名，设置、分类、标签、文档或管理员资料修改后按范围失效，不会累积版本键。
  • 更换 Redis 地址或密码前建议先测试连接。
  • 缓存有效期到期后会自动重新读取数据库。
